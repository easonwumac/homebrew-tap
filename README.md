# homebrew-tap

Homebrew tap for [easonwumac](https://github.com/easonwumac)'s tools.

## Usage

```bash
brew tap easonwumac/tap
```

## Formulae

| Name | Description |
|------|-------------|
| `helm-host` | AI agent relay — monitor and control Codex sessions from your iPhone |

## Casks

| Name | Description |
|------|-------------|
| `helm-app` | Helm macOS menu bar app |

## Install

```bash
# CLI relay (hostd)
brew install easonwumac/tap/helm-host

# macOS menu bar app
brew install --cask easonwumac/tap/helm-app
```
